# Security Policy

## Supported Versions

Only the latest versions for now

## Reporting a Vulnerability

Our build script clones the stable releases 
of the applications we are porting and applies patches
to them for working on Android

Since we have a strict policy of 
modifying zero source code upstream, we can't do anything
about security vulnerabilities present in those repositories.
If upstream fixes them, then they'll be reflected on our repo too.


With that being said, feel free to report any security vulnerability
if you find one, we'll try to patch them in the next update
